# Video Background Files

Place your animated solar plant background video files here:

- `solar-plant-background.mp4` - Main video file (MP4 format, recommended)
- `solar-plant-background.webm` - Alternative format for better browser compatibility (optional)

## Recommended Video Specifications:
- Format: MP4 (H.264 codec) or WebM
- Resolution: 1920x1080 (Full HD) or higher
- Duration: 10-30 seconds (will loop automatically)
- File Size: Keep under 5MB for optimal loading
- Frame Rate: 30fps recommended

## Alternative: GIF Background

If you prefer using a GIF instead of video, place it at:
`/public/images/solar-plant-background.gif`

The component will automatically use the GIF as a fallback if video files are not found.
