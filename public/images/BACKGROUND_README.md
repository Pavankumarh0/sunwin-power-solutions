# Background Media Files

## Animated Solar Plant Background

If you're using a GIF instead of video, place your animated solar plant GIF here:

- `solar-plant-background.gif` - Animated GIF file

### Recommended GIF Specifications:
- Format: GIF (animated)
- Resolution: 1920x1080 (Full HD) or higher
- File Size: Keep under 3MB for optimal loading
- Loop: Should loop seamlessly

The Hero component will automatically use this GIF as a fallback if video files are not available.
